# Speak Sphare 🌐

**Master English Communication** - An interactive Learning Management System (LMS) built with React, Vite, and Tailwind CSS.

![Speak Sphare](https://img.shields.io/badge/React-18.3-blue)
![Vite](https://img.shields.io/badge/Vite-7.3-purple)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.4-cyan)

## ✨ Features

### 🎯 Core Features
- **Interactive Home Page** - Engaging hero section with stats and feature showcase
- **Course Catalog** - Browse 4 comprehensive English learning courses (Beginner to Advanced)
- **Practice Zone** - Interactive exercises for pronunciation, speaking, vocabulary, and listening
- **Learning Dashboard** - Track progress, view recent activity, and unlock achievements
- **User Profile** - Manage account information and view learning statistics

### 🎨 Design Highlights
- **Modern UI** - Glass morphism effects with vibrant gradients
- **Fully Responsive** - Optimized for mobile, tablet, and desktop
- **Smooth Animations** - Custom animations using Tailwind CSS
- **Custom Color Palette** - Primary and secondary color schemes
- **Icon Integration** - Beautiful icons from Lucide React

### 🚀 Animations
- Fade in/out effects
- Slide animations (left, right, up, down)
- Float animations
- Glow effects
- Hover transformations
- Recording pulse effects

## 📦 Tech Stack

- **Frontend Framework:** React 18.3
- **Build Tool:** Vite 7.3
- **Styling:** Tailwind CSS 3.4
- **Routing:** React Router DOM 7.0
- **Icons:** Lucide React 0.468
- **Language:** JavaScript (ESNext)

## 🛠️ Installation

1. **Clone the repository:**
```bash
cd "Speak Sphare"
```

2. **Install dependencies:**
```bash
npm install
```

3. **Start development server:**
```bash
npm run dev
```

4. **Build for production:**
```bash
npm run build
```

5. **Preview production build:**
```bash
npm run preview
```

## 🎨 Tailwind Configuration

Custom animations and color schemes are defined in `tailwind.config.js`:

- **Custom Colors:** Primary (blue-purple) and Secondary (purple-pink) gradients
- **Custom Animations:** fade-in, slide, float, glow, bounce-slow, pulse-slow
- **Utility Classes:** glass-effect, gradient-text, card-hover
